# WebSearch検索クエリ集

## 使い方

`[企業名]` と `[銘柄コード]` を実際の値に置き換えて検索する。
優先度「必須」は常に実行、「推奨」はできるだけ実行、「オプション」は時間に余裕があるときに実行。

---

## 必須クエリ（常に実行）

### ビジネスモデル・収益構造
```
[企業名] ビジネスモデル 収益構造 セグメント
[企業名] 事業セグメント 売上構成
[企業名] 事業内容 わかりやすく
```

### 直近決算・業績
```
[企業名] 決算 業績 売上 営業利益
[銘柄コード] 決算 2026
```

### 財務指標
```
[企業名] ROE 自己資本比率 財務 配当
```

### 競合・市場
```
[企業名] 競合 市場シェア
```

### 株価指標
```
[銘柄コード] PER 株価
```
